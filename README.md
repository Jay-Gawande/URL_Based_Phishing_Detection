# URL_Based_Phishing_Detection
In this project, we propose a machine learning-based phishing website detection system that analyzes URL and website-related features to classify a given website as either phishing or legitimate.
ML model used - Random forest classifier
##  Features
- Detects phishing websites using ML model
- Real-time URL analysis
- Displays prediction (Safe / Phishing)
- Shows probability score
- Feature transparency (explains why a URL is flagged)
- Simple and user-friendly web interface

---

##  Tech Stack
- **Language:** Python  
- **Machine Learning:** Scikit-learn (Random Forest)  
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Flask  
- **Libraries:** Pandas, NumPy, Joblib  

##  Dataset
- **Dataset Used:** LegitPhish Dataset  
- Contains labeled URLs:
  - `0 → Legitimate`
  - `1 → Phishing`
